1: criar o container
docker compose -f docker/compose.yml -f docker/dev/compose.yml build --build-arg USER_ID=1000 --build-arg GROUP_ID=1000 --build-arg USER_NAME=appuser --build-arg GROUP_NAME=appuser app

2: colocar no ar 
docker run --rm -v %cd%:/app -w /app -p 8080:8080 php:8.2-cli php -S 0.0.0.0:8080 -t public

3:arrumar o erro/ instalar o compose
docker run --rm -v "${PWD}:/app" -w /app composer/composer install
